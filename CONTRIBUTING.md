# Contributing

Dies ist ein persönliches Projekt und wird trunk-based direkt auf `main`
entwickelt; externe Pull Requests werden derzeit nicht angenommen.

Fehler oder Ideen gerne als [Issue](../../issues) melden.

Für die Entwicklung gelten die Leitplanken aus `CLAUDE.md` und `AGENTS.md`
(Teststrategie, Definition of Done, Datenschutzregeln). Lokaler Einstieg:
siehe `README.md` und `DEPLOYMENT.md`.
